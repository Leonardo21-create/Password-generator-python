# Secure Password Generator 🔐

PassGenerator is a secure, robust, and simple tool developed in Python. It allows you to create strong passwords according to your preferences (length and format) in just a few seconds.

Additionally, PassGenerator features an **encrypted file system** where your credentials (site, username, and password) remain perfectly safe, accessible only via your **master password**.

## ✨ Features
* **Random Generation:** Includes letters, numbers, and symbols.
* **Secure Storage:** Uses data encryption to keep your data safe.
* **CLI:** Easy-to-use Command Line Interface.
